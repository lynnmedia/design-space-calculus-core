# Design-Space Calculus Core RC1

This bounded developer preview compiles DSC-PL `language dsc 0.1` to typed `DSC-IR-v0.1`, validates conformance, initializes minimal workspaces, and imports `novum-dsc/0.1` with a preservation ledger. This preview supports Python 3.12 only and has no non-standard runtime dependencies.
