# Security reporting

Supported public preview: 0.2.0rc1. Please use GitHub's private vulnerability reporting for the official Design-Space Calculus Core RC1 public repository. If that feature is unavailable, open an issue asking for a private reporting route without posting the vulnerability details or any private data. Include the affected command, Python version, a minimal reproduction, and expected impact through the private route.

This preview carries no hosted service or response-time support commitment.
